## D003 已被D006替代（旧API保留）：源码分析采用有边界的 AST/文本调查
使用真实文件、SHA、哈希和 AST 调用线索；二开候选标为假设，不能推断完整调用图或全面缺口。替代方案让无凭证 fake 模型宣称理解真实仓库会误导。当前不增加复杂静态分析框架；优先将端到端事实闭环做实。后续若用户需要更精准链路，再以真实模型和人工标注验证增量价值。

## D004 有效：显式 SQLite 读事务
浏览器验证发现后台任务完成事务与工作区多表查询可能交错，使完成状态与结论不一致。禁用 sqlite3 legacy transaction control，为 SELECT 显式 BEGIN，保证一个响应读取同一快照。验证：修复后核心 E2E 通过。替代仅调整查询顺序不足以保证整个工作区响应一致。

## D005 有效：中断显式重试与写入事务
